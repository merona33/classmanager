  담임의 노트 — 학급 운영 일지 (맥 PWA 앱)
═══════════════════════════════════════════════════

  ★ Electron 충돌 문제 없이 일반 앱처럼 쓸 수 있는 PWA 방식입니다.
  ★ Node.js 설치 필요 없음, 빌드 필요 없음, 인터넷도 필요 없음.


┌──────────────────────────────────────────────┐
│  ⚠️  이전 Electron 앱이 설치되어 있다면     │
└──────────────────────────────────────────────┘

  응용 프로그램(Applications) 폴더에서
  "담임의 노트" 앱을 휴지통으로 끌어다 버리세요.


┌──────────────────────────────────────────────┐
│  처음 한 번 — 실행하고 앱으로 설치           │
└──────────────────────────────────────────────┘

  ① 이 폴더 안의 "담임의노트_실행.command" 를
     마우스 오른쪽 클릭 (또는 control+클릭) → "열기" 선택
     → 경고창에서 "열기" 다시 클릭

     ※ 검은 터미널 창과 함께 브라우저가 자동으로 열립니다.
     ※ 이 터미널 창은 닫지 마세요 (서버가 동작 중).

  ② 브라우저(Chrome 또는 Safari)에 앱이 열립니다.

  ③ 앱으로 설치하기:

     【 Chrome 사용자 】
     - 주소창 오른쪽 끝의 ⊕ 아이콘 클릭
       (또는 메뉴 → 캐스트, 저장 및 공유 → 페이지를 앱으로 설치)
     - "설치" 버튼 클릭
     - Launchpad와 Dock에 "담임의 노트" 아이콘 생성됨

     【 Safari 사용자 】
     - 메뉴 막대 → 파일 → "Dock에 추가..." 클릭
     - 이름 확인 후 "추가" 클릭
     - Dock에 "담임의 노트" 아이콘 생성됨


┌──────────────────────────────────────────────┐
│  매일 사용                                   │
└──────────────────────────────────────────────┘

  방법 1 (Chrome 설치) — Launchpad/Dock의 "담임의 노트" 클릭
       → 검은 터미널 창은 자동으로 안 뜸, 진짜 앱처럼 실행됨
       ※ 단, 백그라운드에서 실행 스크립트가 켜져 있어야 합니다.

  방법 2 (간단) — 이 폴더의 "담임의노트_실행.command" 더블클릭
       → 터미널 창이 열리고 브라우저에 앱이 표시됨
       → 끝낼 때는 터미널 창을 닫으면 됩니다.

  💡 가장 편한 방법:
     - "담임의노트_실행.command"를 마우스 오른쪽 클릭
     - "별칭 만들기" 선택
     - 만들어진 별칭(alias)을 바탕화면이나 Dock으로 끌어다 놓기
     - 이제 더블클릭 한 번으로 실행 가능


┌──────────────────────────────────────────────┐
│  자동 시작 설정 (선택)                       │
└──────────────────────────────────────────────┘

  맥 켤 때마다 자동으로 시작되게 하려면:

  ① 시스템 설정 → 일반 → 로그인 항목 및 확장 기능
  ② 로그인 시 열기 → ⊕ 버튼
  ③ "담임의노트_실행.command" 선택
  ④ 다음부터 맥 켜질 때 자동으로 서버가 시작됩니다.


┌──────────────────────────────────────────────┐
│  학교 컴퓨터에도 설치하려면                  │
└──────────────────────────────────────────────┘

  이 폴더 전체(class-manager-pwa)를
  USB나 클라우드로 학교 맥에 복사하세요.

  복사한 폴더에서 "담임의노트_실행.command"를
  처음 한 번 우클릭 → 열기, 그 다음부터는 더블클릭으로 실행.


┌──────────────────────────────────────────────┐
│  데이터 저장 위치                            │
└──────────────────────────────────────────────┘

  모든 자료(명렬표, 성적, 자리, 상담)는
  브라우저의 로컬 저장소(localStorage)에 저장됩니다.
  외부로 전송되지 않습니다.

  ⚠️ 학교 맥과 집 맥은 데이터가 별도로 저장됩니다.
  ⚠️ 같은 컴퓨터라도 Chrome과 Safari는 별도 저장됩니다.

  자료 옮기기/백업:
  - 각 화면의 "엑셀 다운로드"로 백업
  - 다른 컴퓨터/브라우저에서 "엑셀 업로드"로 복원


┌──────────────────────────────────────────────┐
│  문제 해결                                   │
└──────────────────────────────────────────────┘

  ▸ "확인되지 않은 개발자" 경고가 뜬다
    → 우클릭 → "열기" → 다시 "열기" (한 번만 하면 됨)

  ▸ 브라우저가 안 열린다
    → 터미널 창의 메시지에 나오는 주소 (보통 http://localhost:8765/)를
      복사해서 브라우저 주소창에 직접 붙여넣기

  ▸ "Python이 필요합니다" 경고
    → 터미널 앱 열고 명령어 입력: xcode-select --install
    → 설치 완료 후 다시 실행

  ▸ 포트 충돌
    → 다른 8765 포트를 쓰는 프로그램이 있는 경우 자동으로 8766, 8767... 시도
